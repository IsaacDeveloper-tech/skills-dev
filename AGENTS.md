# AGENTS.md

## 1. General Principles
- Understand the requirements before making changes.
- Prefer simple, maintainable solutions over unnecessary complexity.
- Follow existing project conventions and respect the current architecture.
- Avoid unrelated changes, speculative features, and premature optimizations.

## 2. Development Workflow
- Inspect relevant code before modifying it.
- Work incrementally, implementing one backlog slice at a time.
- Explain significant decisions and consult the developer when requirements are ambiguous or a decision has meaningful consequences.
- Validate changes before considering them complete.

## 3. Testing and Verification
- Run relevant tests and checks whenever possible.
- Never claim that a test or check passed unless it was actually executed successfully.
- Clearly report failed, blocked, or unexecuted validations.

## 4. Developer Collaboration
- Treat the developer as the final decision-maker on requirements and significant technical decisions.
- Preserve existing user changes and never overwrite them without permission.
- Do not commit, push, or publish changes unless explicitly requested.

## 5. Project Instructions
- Read and follow `CONSTITUTION.md` for project-specific architecture, coding conventions, and technical standards.
- Follow the project's documented workflows, tools, and instructions.
- Ask for clarification when essential information is missing rather than inventing requirements.
